# 釣り手帳 サポートサイト

https://easpe.github.io/tsuri-techo/ で公開する静的サイト（GitHub Pages、main の / から）。
原本はアプリのリポジトリ（Easpe/TsuriTetyou）の `site/`。公開用のリポジトリ Easpe/tsuri-techo にはこのフォルダの中身だけを置く。

- index.html：アプリの紹介
- support.html：よくある質問と問い合わせ（info@easpe.jp）
- privacy.html：プライバシーポリシー（日本語・English）
- tokushoho.html：特定商取引法に基づく表記（T-934）。所在地・電話番号・責任者は「請求があれば遅滞なく開示」（特商法 11 条のただし書き）。アプリの「このアプリについて」とプランの画面から開く
